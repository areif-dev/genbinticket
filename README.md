# Genbinticket

Utility to generate printable bintickets from ABC bills and inventory data. Labels are compatible with Avery 5160 label paper. 

## Building For Windows

```bash 
cargo build --target=x86_64-pc-windows-gnu --release
```

## Required Data from ABC 

This program requires both up-to-date inventory data and a specific data on a bill (or list of bills). This data can be generated by running reports 7-10 and 2-16, respectively.

### Report 7-10 Export Tables to SQL

This report dumps all data from the requested ABC files into formatted text files at `C:\ABC Software\Database Export\Company001\Data`.

To generate bintickets, you will need to export the Inventory file specifically. Start by logging into ABC, as operation requires administrator access. Then run report 7-10 by entering the sequence F10, 7, 10, then enter "I" into the field asking for file characters. You may safely skip all other options of the report, including the output format. 

### Report 2-16 Bill Detail 

Report 2-16 contains details about bills entered into ABC, including line items, costs, totals, etc. The generator will create bintickets from the line items of this report.

To generate report 2-16, start by copying the bill number for which you would like to generate bintickets. Then enter the sequence F10, 2, 16. Paste your bill number into the report generator (the generator can actually handle more than one bill at once, so you can supply a range of bills). Finally enter "T" into the output field to send the report to a tab separated values file located at `Documents\My ABC Files\TabOutput.tsv`.

## Running the Generator 

You can simply run the executable genbinticket.exe. By default the app will look for reports 7-10 and 2-16 in their default file locations. If either report is not in its default location for some reason, the generator provides various command line options to set the paths manually. Those options are outlined below 

Usage: genbinticket [OPTIONS]

Options:
*  -t, --tabfile <TABFILE>          Path the the TSV file containing the data for ABC report 2-16 (Bill Details) [default: "C:\\Users\\User\\Documents\\My ABC Files\\TabOutput.tsv"]
*  -d, --detail-file <DETAIL_FILE>  Path to the ABC Item Detail file obtained by running report 7-10 (SQL Export) [default: "C:\\ABC Software\\Database Export\\Company001\\Data\\item.data"]
*  -p, --posted-file <POSTED_FILE>  Path to the ABC Item Posted Data file obtained by running report 7-10 (SQL Export) [default: "C:\\ABC Software\\Database Export\\Company001\\Data\\item_posted.data"]
*  -D, --debug                      Enable debug mode, which starts the server on 0.0.0.0
*  -h, --help                       Print help
